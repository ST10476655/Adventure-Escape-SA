# Project Overview

Adventure Escape SA is a tourism and adventure website designed to promote outdoor adventure experiences throughout the Western Cape, South Africa.

The website allows visitors to:

- Learn about Adventure Escape SA
- View available adventure packages and activities
- Calculate estimated booking fees
- Request quotations
- Submit booking enquiries
- Contact the company

---

# Features

## Home Page

The Home Page introduces visitors to Adventure Escape SA and highlights featured adventures.

Features:

- Company logo
- Navigation menu
- Hero image
- Introduction section
- Start Your Adventure button
- Featured adventures section
- Footer with contact details

---

## About Us Page

Provides information about the company.

Features:

- Company history
- Mission statement
- Vision statement
- Why Choose Us section
- Company values

---

## Overview Page

Displays all available adventure packages and activities.

Features:

- Search bar
- Package catalogue
- View Details buttons
- Navigation to package pages

Packages available:

- Ultimate Adventure Day
- Family Explorer Package
- Mountain Adventure Package
- Corporate Team Challenge
- Ziplining Adventure
- Kayaking Experience
- Rock Climbing Session

---

## Package Detail Pages

Each package page provides information about:

- Price
- Purpose
- Included activities
- Book Now button
- Request Quote button

---

## Fee Calculator

Allows customers to estimate booking costs.

Features:

- Customer information form
- Adventure selection
- Automatic discount calculation
- VAT calculation (15%)
- Quote summary
- Booking request submission

### Discount Rules

| Adventures Selected | Discount |
|---------------------|-----------|
| 2 Adventures | 5% |
| 3 Adventures | 10% |
| More than 3 Adventures | 15% |

---

## Contact Us Page

Provides company contact information.

Features:

- Phone number
- Email address
- Physical address
- Google Map
- Enquiry form

# How To Run The Website

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select **Open with Live Server**.
6. The website will open in your web browser.
